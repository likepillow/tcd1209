# 免下载器启动版（2026-10-04 ADC钳位保护升级）

本版本将FPGA配置写入板载SPI Flash，同时将30 MHz FIFO固件写入FX2的24LC64 EEPROM。供电与J5数据线即可工作，不再需要日常连接JTAG下载器；固件升级和恢复仍使用下载器。

- 原始Flash全片备份：`build/flash_audit/original_flash.bin`，16,777,216字节；SHA256 `3DFA28867BA88EE035BD9E26E24F7717506C7C9A4DCD23EC0A424D7943211C73`。原片有配置数据，不是空片。
- FX2 EEPROM：原理图u19为24LC64（8 KiB）。原始内容连续两次读回一致，前2718字节与用户slave.iic完全一致。备份：`build/flash_audit/original_fx2_eeprom.bin`；SHA256 `55829553FB4CB429DC44D234B8968E53AE2C67E0324C9D7BDF35EC224180274A`。
- 新FX2镜像`build/flash_audit/slave_30mhz.iic`仅在EEPROM偏移1788将E3改为A3，对应8051程序地址0x08DE的IFCONFIG立即数。与先前已验证的30 MHz RAM固件内容一致。
- FX2已经固化且整片读回验证通过，尾部5474字节保留。新整片读回SHA256为`717FA4DC7E67F355EC61597D36105E94FAAAB447ED9026E3E4C616FB234462CC`。

## 自动启动行为

不再使用VIO启动控制。板载100 MHz时钟检查USB IFCLK：30 MHz连续合格后释放通信和配置通路，48 MHz或缺失时不启动。控制版上电默认停止CCD采集；USB连接后上位机再发送一次STOP建立确定状态。点击“开始采集”才启动CCD时序，完成AD9945/模拟稳定等待并丢弃约100 ms稳定阶段的完整帧。没有S/K时仅输出S0；发送有效S/K后才进行解算。

启动位流使用SPI x1、16 MHz配置时钟。当前Flash标记USR_ACCESS=0x26100301，上一控制版0x26092402保留作回退。已约束路径时序WNS=+0.908 ns、WHS=+0.040 ns，USB可行性门限检查为输出setup +6.320 ns、输出hold +3.000 ns、输入setup +14.504 ns、输入hold +0.599 ns。CCD/ADC外部I/O仍有未约束延时，USB也未包含实际PCB传播延时，不能称为完整板级生产签核。

已固化文件为`build/clipping_deploy/instrument_clipping.bit`、`.mcs`和`.bin`，SHA256分别为`7B1ADC9B5680D0FF34C31CA44EDC8FBCC7F07F7D4CC5212CCB6BD1531C135412`、`6571877702F9EAF4D570FDB9488BE91DBE9DE69F82F03EA4056279A78E162CEF`、`FFEDAF543B737C9CD29D9AE6A10FD59D9F9AEA8BB0C8568D87DEBF5FFA1E526A`。上一控制版`build/control_deploy`及`build/clipping_flash_audit/flash_before_program.bin`整片备份保留作回滚依据。FX2 EEPROM本次未改动。

## 日常操作

1. 接好B板、专用电源及J5数据线。无需连接下载器，也无需启动Vivado或重新加载FX2固件。
2. 上电后等待约2秒，双击`build/viewer_dist/viewer.exe`，点击“连接USB”并选择同目录CyUSB.dll；等待“USB已准备/采集停止”。
3. 设置W（0～1024）和T（422.8～999.8 μs、步进0.2 μs），点击“应用W/T”并等待ACK。默认值为512/422.8 μs。
4. 推荐S0输出间隔设为100，点击应用并确认ACK成功。该显示间隔不改变采集和算法帧率。
5. 读取与当前W/T匹配的S/K标定，点击发送至FPGA，确认两项ACK成功。S/K存于FPGA易失RAM，修改W/T或断电后必须重新发送。
6. 点击“开始采集”，约100 ms后检查S0/RESULT。按操作说明保存SPIF、距离CSV或曲线TXT。
7. 结束时点击“停止采集”或“断开USB”，等待停止确认后再关闭或断电。

注意：控制版正常关闭窗口会先停止CCD并等待排空ACK；ACK失败时阻止关闭并报警。异常进程终止、USB突然拔出不承诺自动停机，此时应恢复连接安全停止或人工断电。更改硬件接线必须断电。旧版`set_board30_acquisition.tcl`为VIO调试版专用，不能控制此版本。不要重新烧回48 MHz FX2固件，否则时钟保护会阻止启动。

若要重新进行完整冷启动，必须切断所有可能的供电路径（包括可能供电的USB线），确认板上电源指示灯熄灭，再恢复专用电源及J5；不要只断开专用电源而让USB继续供电。

## 恢复及升级

保存`build/flash_audit`、`build/runtime_flash_audit`和`build/runtime_deploy`目录。回滚Flash应使用原始全片备份并核对哈希；不要将BIN内容当作BIT文件直接下载。FX2可用原始slave.iic恢复原功能，也可使用全片备份恢复所有EEPROM数据。恢复或升级应在下载器连接、采集停止的受控状态进行，且再次读回校验。此处不提供无确认的一键擦除入口。

## 构建与依据

使用Vivado 2018.3运行`scripts/build_standalone.tcl`（参数为工程绝对路径），包括自动启动顶层综合、实现和高扇出/接口时序优化；随后运行`scripts/prepare_board30_bitstream.tcl`，参数为工程根目录、新输出目录、`standalone`。生成脚本拒绝隐式覆盖已有位流。`scripts/test_standalone_clock.ps1`复现时钟资格检查仿真；Python主机回归使用`python -m unittest discover -s sim -p 'test_*.py'`。

硬件依据为用户提供的ACX720-V3原理图第2、5页，并经实板启动引脚、Flash JEDEC ID和EEPROM读回交叉核对。工具流程参考[AMD配置存储器读回](https://docs.amd.com/r/en-US/ug835-vivado-tcl-commands/readback_hw_cfgmem)、[AMD SPI启动接口](https://docs.amd.com/r/en-US/xapp586-spi-flash/SPI-Flash-Configuration-Interface)及[Infineon FX2 EEPROM读回说明](https://community.infineon.com/t5/Knowledge-Base-Articles/Reading-Serial-EEPROM-which-is-Connected-to-the-FX2/ta-p/254704)。实际命令还核对了本机Vivado 2018.3帮助和CyUSB库接口。
