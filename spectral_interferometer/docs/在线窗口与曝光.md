# 在线窗口与曝光配置

本功能需要带 `ACQUISITION` 命令的新版 FPGA 固件（USR_ACCESS `26092401`）。
2026-09-24 已完成 RTL 边界仿真、布局布线、临时下载、实机 USB 测试、Flash
烧写、全片读回校验和 Master-SPI 重启验证。历史固件不会执行该命令。

- W 为原始2048个有效像素的零基起点，范围0～1024；S0对应W～W+1023。
- T 为稳定连续工作时的SH周期，范围422.8～999.8 μs，步进0.2 μs。
- 采用5 MHz读出配置，以增加帧尾等待调节T；标称帧率为1000000/T Hz。
- T小于1000 μs，因此整个允许范围的标称采集率都严格超过1000 Hz；T=999.8 μs时为1000.20 Hz。

点击“应用 W/T（清除标定）”后，设备完成当前CCD帧、排空采集缓存和计算/发包通路，再切换参数并复位算法标定。
USB传输和全局包序号不复位。设备确认后重新启动采集，启动保护期间暂不发布光谱。
上位机仅在收到成功确认后更新已应用配置；随后应重新发送对应的S/K。
重新连接设备后应再次应用W/T以建立上位机可确认的配置；W/T寄存器不单独写入非易失存储，FPGA每次启动恢复W=512、T=422.8 μs。

S采用新窗口对应的1024点。2048点S/K文件按W裁剪；1024点K取相对下标256～767，512点K直接对应拟合段。
NPZ标定文件保存W和T；历史无此字段的标定按W=512、T=422.8 μs解释。
在线记录的manifest.json保存W/T成功确认的包位置；回放时请将manifest.json与stream.spif放在同一目录。

协议新增类型0x24，载荷8字节：小端u32的W及小端u32的period_pixels（T/0.2 μs）。
CRC、范围检查通过才发布命令，设备完成切换才发送原ACK格式的成功确认。
无效W/T命令不会修改设备状态；上位机的确认超时不能视为成功。

## 实机结果

- W=0、512、1024均收到状态0 ACK，并在变更后重新发布完整1024点帧。
- T=500.0、422.8、999.8 μs的帧时间戳分别精确为50000、42280、99980个100 MHz tick。
- 单USB会话内完成W/T、S/K和关闭S0输出后，连续收到500个RESULT帧，帧号逐1递增、时间戳间隔均为42280 tick（2365.18 Hz），丢帧/异常/CRC均为0。
- Flash启动复测中ADC有效范围约296～693，65个包的包头、CRC和载荷错误均为0。

以上证明数字配置、CCD帧采集和结果通道吞吐；真实干涉条纹的距离正确性仍需用用户光路、S和K做最终标定。
