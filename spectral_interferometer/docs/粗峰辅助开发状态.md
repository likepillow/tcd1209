# 粗峰辅助功能开发状态（未部署）

2026-10-04用户确认：粗峰算法若无精度收益可以抛弃，只保留精度最高的方法。本批实测粗峰法不如相位斜率法，因此不再开发或部署FPGA粗峰辅助功能。当前固化26100301及其采集/相位解算不变；下述独立原型和离线比较仅保留为研究记录，不属于生产链路或待交付功能。

`rtl/coarse_peak_fit.v`实现三点**功率**抛物线亚频点偏移：

delta = (P右-P左) / [2 × (2P中-P左-P右)]。

输入为65位无符号功率，与现有H0功率格式一致；输出为21位有符号Q1.20，限制到±0.5 bin，整数除法采用逐位分数除法并作最近偶数舍入。平峰、零峰、非局部最大及正频搜索边界1/511给出辅助INVALID和零偏移，不改变精细相位结果的标志。除法延迟上界22时钟，100 MHz时约0.22 μs；这是独立模块仿真延迟，不是整条混合链的实现签核或实机帧率。

`scripts/test_coarse_peak.ps1`通过313个精确有理数参考向量，覆盖对称/非对称峰、符号、±0.5边界、65位最大功率及输出反压。记录在`build/coarse_peak_sim/xsim.log`。当前RTL没有读取FFT邻点、距离单位换算、帧ID/S/K版本关联、独立粗峰包或粗细一致性门限，不能宣称原混合架构已经实现。

不实施原计划中的FFT邻点接入、独立粗峰包及粗细一致性门限。K非均匀情况下频点换算只是粗近似；本批线性和自然三次样条重采样均未过收益门限，也不进入FPGA。保留当前复数主峰滤波、IFFT相位展开及真实K斜率拟合；参考S的31点平滑是本批最佳候选，仍须独立光学复测，不能宣称普遍最优。
