# 曝光、可控LED及科研导出升级（2026-10-24）

最新固化版为26102402，已完成备份、写入、全片校验及整板断电后的免下载器USB复测，本轮升级按实验原型范围验收完成。新版应用在build/viewer_research_dist/viewer.exe（同目录CyUSB.dll需保留），原版在viewer_dist不覆盖。连接新版FPGA后，务必选择“12.5 MHz新版”，再设置曝光和距离输出间隔并应用；上位机仍保留5 MHz旧版选项用于回滚兼容。

## 曝光与输出设置

旧5 MHz模式继续使用原0x24命令，T为422.8～999.8 μs，仅用于旧固件兼容。新版选择“12.5 MHz新版”，曝光周期T最小200 μs、步进0.08 μs，采用64位像素周期计数；软件不设置常规的长曝光上限，但会拒绝计数溢出（最大2^61−1个80 ns周期，约5845年，绝非器件可在此曝光下保持有效的保证）。长曝光会受到暗电流、饱和和光学稳定性的实际限制。

T仍是相邻SH之间的积分/帧周期，不是独立电子快门。12.5 MHz时一行2088点读出167.04 μs，SH高宽保持1.6 μs、前后保护各0.64 μs；200 μs有足够的数字调度余量。CCD端模拟边沿和采样相位仍需实物质量验证，不能把数字模型当作完整电气签核。

“距离每N帧输出”独立控制RESULT选取，实际输出率为1/(T×N)，不强制高于1000 Hz，也不重复旧结果。200 μs时N=4、5、6分别约1250、1000、833.33 Hz；10 ms、N=1时约100 Hz。内部仍对每个完整采集帧运行算法。“S0输出间隔”独立控制光谱抽帧，不能从抽帧记录恢复未保存的光谱。

应用新版W/T/N命令会安全排空、重置处理标定，随后必须重新上传S/K。曝光或像素时钟不同的参考S不能自动复用为同一标定。新版标定NPZ保存pixel_ticks；旧标定默认20 tick/像素，新版为8 tick/像素。

新版长曝光停止：完成当前CCD读出和ADC尾部后，可结束尚在等待下一SH的长积分尾段，不必等到几分钟或几小时后才能关闭上位机；不会截断已经输出的完整帧。

## 可控LED

ACX720-V3的D0～D7为高电平点亮，新顶层明确输出8'b0；引脚依次M22、N22、L21、K21、K22、J22、H22、M21，LVCMOS33/4mA/SLOW。原先未使用引脚的弱上拉不再作为这些灯的状态来源。

开发板D19/D21电源灯、B板DS1（VCC5V→R16→LED→GND）不受FPGA控制，仍需绝缘、不透光遮罩；下载器/其他接口灯也不能一概通过用户逻辑关闭。不要为了灭灯关闭整条3.3 V/5 V供电。参考示意图渲染与读图记录在build/exposure_led_review。

## SPIF原始存档＋HDF5科研数据＋CSV

采集仍首先写原始stream.spif，同时写distance.csv和manifest.json，不在USB接收线程做HDF5压缩。新记录额外保存成功ACK对应的配置字节及S/K原始数组、单位/比例和标定版本。离线回放另存时也保留已回放范围内的配置事件；旧记录没有的信息保持未知，不虚构。

采集前先勾选“保存接收流和距离CSV”，再连接USB并选择新的记录目录。曲线窗口只保留最近数据，未记录的历史帧不能事后补回。显示刷新率不等于保存帧率。

新版viewer有“科研导出 HDF5/CSV”：选择已结束的SPIF、新建输出目录，输入可选帧号区间（如1140000:1140999），选择是否额外输出全部选中光谱CSV。转换为后台分块任务，可继续操作界面；关闭时若导出未结束，先请求取消并保留部分文件及报告，再关闭。USB正常停机仍必须STOP ACK。

导出目录包含research.h5、distance.csv、report.json；选择后还包含spectra.csv。输入和已有输出目录均不覆盖。取消、坏CRC、缺包或断尾时默认不发布最终research.h5，保留research.partial.h5和失败报告。命令行显式--allow-damaged可恢复可信包，但integrity_ok仍为false；不得把这种文件称为无损记录。

新版exe也支持无界面批量转换，例如：

```powershell
.\viewer.exe --export-spif "D:\record\stream.spif" --export-to "D:\exports\run01" --spectra-csv
```

退出码0表示转换完成，2表示失败；查看输出报告。源码命令为python host/research_export.py 输入.spif 新目录，可用--frame-min/--frame-max和--allow-damaged。

### HDF5结构及精度

|路径|内容|
|---|---|
|/spectra/s0|uint16，文件逻辑维度为帧×1024像素，原ADC值不平滑|
|/spectra/pixel_offset|0..1023；绝对有效像素下标为每行W+offset|
|/results|distance浮点值、invalid、精确12字节有符号累加值及exponent、主峰范围和设备计数|
|/processed|仅当记录含SPECTRUM时，保留S1/S2整数值，除4096得到实际值|
|/phase|仅当记录含PHASE时，保留P1整数，乘π/2^31得到弧度|
|/calibration|成功ACK的命令载荷及新上位机记录的实际S/K数组、单位、比例和版本；旧记录可能为空|
|/manifest_json、/boundaries_json|原始元数据和分段/告警事件|

光谱、距离、处理谱和相位都有各自帧号、uint64时间戳、标志、版本、段号和源包索引。按segment_id和frame_id关联，不按行号关联；RAW的标定版本可能为0，不能要求RAW版本与RESULT版本相等。设备复位或配置边界须区分；单独的“不连续”位也可能来自有意抽帧，不能直接当作新复位段。矩阵维度见axis_order属性，MATLAB读示例返回帧×像素。

time_seconds相对各段首个有效测量包时间戳，保留原始100 MHz整数tick；没有有效时间戳的记录不伪造硬件时间。RAW和RESULT可能交错，因此同段稍早帧的相对时间可能为负。未知W编码−1，未知周期/像素tick编码0。距离单位取决于实际K和距离比例，缺失时保持未知。

integrity_ok只表示包字节流完整性，不意味着保存了全部CCD帧、更不证明光学准确度。RAW抽帧/间断另有data_continuity_warning，原始flags、manifest警告和报告保留。坏包和断尾不会被悄悄跳过后标为完整。普通HDF5不是MAT v7.3文件，MATLAB使用h5read，不使用load。

读取示例在examples/read_spif_hdf5.m和examples/read_spif_hdf5.py。MATLAB示例支持分别指定S0和RESULT行区间，不默认把所有RESULT装入内存；本次未找到可运行的MATLAB，尚未执行该.m示例。Python/h5py及封装exe的实际HDF5读写已做自动检查。
