# 外部接口时序核查与最少测量（2026-10-04）

## 结论

当前固化26100301已实机采集和处理吞吐验证，但不能仅凭手册把剩余13输入/15输出全部补上有保证的最坏情况延时。不要用任意input/output delay、宽泛false path或放宽时钟来消除报告告警。

视觉核对AD9945 Rev.C第4页时序表：tOD=9.5 ns位于Typ列，Min/Max为空；10周期流水线也列于Typ。SHP/SHD的6.25 ns是典型脉宽，不能误写为手册保证的最小脉宽。表中明确最小值包括DATACLK周期25 ns、高/低脉宽10 ns，以及串口10 ns建立/保持。源文件来自Analog Devices官方[AD9945手册](https://www.analog.com/media/en/technical-documentation/data-sheets/ad9945.pdf)，本地核对页见build/io_timing_review/ad9945.pdf。

TCD1209DG Rev.2.4第8页表中SH最小宽度1000 ns，SH与CP/RS隔离至少200 ns，φ1/φ2交越要求t20至少17 ns；典型参数的测量条件为1 MHz。当前SH逻辑高宽1600 ns、前后保护600 ns属于RTL数字时序，不能替代B板驱动之后的实际幅度、边沿和交越测量。源文件为用户提供的TCD1209DG_Web_Datasheet_en_20260424.pdf。

## 当前数字时序

100 MHz内部系统时钟；DATACLK周期200 ns。adc_pixel_align在DATACLK逻辑发出后两个系统时钟（20 ns）读ADC总线；实际DATACLK到达AD9945还包含FPGA输出路径和板/排线延迟，返回数据又包含ADC输出及输入路径延迟。

因此不能将“20 - 9.5 = 10.5 ns”直接当作建立裕量。必须同时考虑输出路径、往返板级延迟、输入路径、捕获寄存器建立时间、时钟偏差及抖动。9.5 ns没有保证最大值，还需器件额外依据或实测工作条件下的工程边界。

scripts/audit_frontend_io.tcl只读现有refined.dcp，使用临时诊断边界提取正常工作寄存器到引脚、ADC引脚到捕获寄存器的布线路径。100 ns诊断MaxDelay不是批准的外部接口预算，其正Slack不代表签核通过；脚本不保存检查点、不生成位流、不下载/写Flash。输出在build/io_timing_review/routed_frontend_delays.tsv及相关rpt。早期脚本调试日志保留，不把失败或复位路径混入结果当作正常数据路径。

最终audit_retry3.log通过，未出现路径分割告警。正常DATACLK寄存器时钟脚到FPGA输出引脚的数据路径最小/最大为3.950/8.343 ns，ADC输入引脚到捕获寄存器D的数据路径为1.799/5.452 ns；均是Vivado器件模型，不是示波器实测。PBLK为常量，无翻转寄存器路径，不能把无路径当错误。

一个需明确的风险：若把两段FPGA最大模型延迟与ADC典型值简单相加，得到8.343+9.5+5.452=23.295 ns，已经大于当前20 ns逻辑捕获间隔，且尚未加入排线/板级延迟、时钟差与建立时间。此混合估算不是完整最坏情况STA，也不证明当前板必然出错（实机采集已通过）；但它足以否定“20 ns已保证充分”的说法。应优先测量实际稳定窗口，并评估延后捕获或输入IOB寄存器优化的候选；候选需重新仿真/实现/实机测试，不凭典型参数直接覆盖当前镜像。

## 最少测量顺序

先确认示波器带宽、通道数和探头规格，再执行；建议低电容探头和短接地弹簧。普通接地台式示波器的地夹只接已确认的电路公共地，不接信号或电源正极。先停采再接探头，避免在密集芯片引脚间短路；优先现有测试点/排线接口，不能凭照片猜测引脚方向。

1. B板CCD端SH和φ1：核对SH高低电平、宽度、保护间隔及边沿。测RS/CP在SH期间保持低，必要时分别重复。
2. CCD端φ1/φ2：核对交越电平及t20；FPGA端的3.3 V数字波形不是CCD端5 V驱动波形。
3. AD9945端DATACLK及SHP/SHD：核对周期、占空比、取样相位及边沿。数字波形正确仍不证明模拟OS已稳定。
4. DATACLK在AD9945脚处与D0～D11在FPGA接口处：逐组测量数据最早/最晚变化，使用多次采集和持续显示；选择非恒定RAW输入，否则位线不翻转无法给出有效延迟。记录负载/探头影响，测量报告不能冒充全温度保证。
5. 如需完整板级生产签核，还要补充FX2接口PCB延迟及温度/供电/负载边界。有限实验室测量最多支持明确工作条件下的工程验收，不自动代表所有温度和所有器件。

取得这些资料后才可制定保守外部约束，并重新完成实现/实机回归。若20 ns采样窗口不足，需另行调整CAPTURE_DELAY并重新验证，不能只改约束“做绿”；未经候选验证不替换当前Flash。
