# 上位机工作台

入口为 `host/viewer.py`，发布版为 `build/viewer_dist/viewer.exe`。工作台支持 FX2 USB 在线采集、SPIF 记录与回放、S/K 标定、W/T 与 S0 输出间隔配置、光谱/距离曲线和文本导出。

## 在线状态

USB 会话依次经历“连接中→USB 已准备/采集停止→启动中→采集中→停止中→断开中”。连接成功后工作线程先发送 RUN_CONTROL=0，只有收到排空 ACK 才进入准备状态。此时可以配置 W/T、S/K 和 S0 输出间隔，再点击“开始采集”。“停止采集”完成当前帧并排空设备，保留 W/T、S/K 和版本；再次开始时距离曲线插入断点。

同一次 USB 连接内可多次开始/停止，记录仍写入同一个独占会话目录；`manifest.json` 的 `run_events` 保存各次启停位置和相对时间。点击“断开 USB”或正常关闭窗口时，上位机会取消尚未发送的普通命令、等待已发送命令结束，再发送 STOP。STOP ACK 超时或 USB 异常时窗口保持打开并显示红色告警，不能把未确认状态当作安全停机。

## 回放

“打开 SPIF 记录”启动独立回放线程。“停止回放”只控制离线回放，不影响在线 FPGA。默认 1×，可选 0.25×、0.5×、1×、2×、4×和不限速；播放中切换会在当前位置重新锚定，不跳包也不突然追赶。同一时间戳的 RAW/RESULT 等包连续处理，真实停采空档保留。

有 TIME_VALID 时使用 FPGA 100 MHz 时间戳。旧记录缺少时间戳时优先用 manifest 中的 T 和 frame_id；再无 manifest 时采用 422.8 μs 默认值并显示“估算节奏”。不限速只取消等待，不丢包。界面约 20 Hz 刷新不代表采集或保存帧率。

## 曲线与标定

2026-10-03实测评估后新增“平滑参考S（可选）”，宽度默认31，允许3～127之间的奇数，采用反射边界滑动平均。仅修改光源参考S草稿，不修改测量S0、不自动发送FPGA；重复点击同一宽度不会反复叠加滤波。“恢复原始S”可撤回，保存NPZ标定时连同原始S一起保存。仍建议先用128帧逐像素平均降低随机噪声，再按实际光路需要决定是否平滑参考S。

本批11位置数据，原始S相位法P95位移误差约0.334μm，31点参考S平滑约0.208μm；线性K重采样约0.537μm，没有达到20%改善门限，故暂不启用FPGA重采样。该收益来自同批数据，不能代替独立复测。详细数据与可加载的原始S/中间512点K标定位于`build/positions_20261003`。

特别注意：当前固化26092402版的RESULT无效位不会自动拒绝所有ADC饱和场景。上电后先观察S0；若出现0/4095钳位或没有实际条纹，显示的数值即使未标无效也不能用于测量。此次全4095实机输入仍输出约8.62μm，已记录为光学验收失败，不能以其约1666.67Hz包节奏宣称有效测距完成。

S0 总是 1024 点，对应原始 2048 有效像素的 `W..W+1023`。S1/S2/P1 是可选诊断输出，正常部署可以只传 S0 和 RESULT。距离只来自 FPGA RESULT，不由上位机软件 FFT 代算。无效结果、版本改变、缺包和停采空档都使曲线断开；显示历史上限为最近 4096 个结果，磁盘记录不受此限制。

“当前单帧 S0 设为 S（快速）”只适合接线调试。正式标定推荐设置 128 帧并点击“多帧平均设为 S”：工作台对未来收到的完整 S0 逐像素作算术平均，同一帧的 RAW/SPECTRUM 包不会重复计数，带无效标志或含 0/4095 饱和值的帧自动跳过。128 帧使独立随机噪声的标准差理论上降至单帧的 `1/√128≈0.088`，而且平均只在标定时运行，不占用 FPGA 实时测距预算。采集过程中必须保持光路、曝光 W/T 和光强不变。

测量 S0 默认不做滑动平均。干涉条纹本身是待测信号，三点滑动平均的幅频响应为 `(1+2cosω)/3`，会对高频（较远距离）条纹造成更强衰减并可能改变主峰边界。现有去均值和 FFT 主峰复数带通已承担信号选择；若只为改善曲线观感，应在上位机另行平滑显示或用逐结果更新的 IIR，原始结果仍须保存。K 文本接受 512/1024/2048 个有限且严格单调的数值。距离比例直接乘入拟合斜率：K 为 `2π/λ` 且要把双程光程差换成几何距离时通常设 0.5；K 单位只是记录和显示标签，必须与导入 K 的实际单位一致。导入、保存或读取只更新本地草稿，必须点击“发送 S/K 至 FPGA”并收到两个状态 0 的 ACK 才生效。

## 非均匀 K 离线 A/B

数据准备和各阶段验收边界详见[重采样实测数据与验收](重采样实测数据与验收.md)。转换保留无效帧，拒绝CRC错误、缺包、倒序及记录清单中不一致的W/T。A/B报告的无效率包含CCD无效标志；全量程非线性定义为各位置平均偏差绝对值最大值除以已知距离跨度（仅首位置零点校正）。峰值SNR以正频主峰功率对带外功率中位数计算；软件耗时统计不能代替FPGA实时速率。

已有SPIF记录可通过`host/prepare_ab_dataset.py`转成NPZ。JSON清单示例（路径相对清单文件，truth单位与距离输出一致；降序K按现有正频相位约定使用负的truth）：

```json
{
  "source": "source.txt",
  "k": "k.txt",
  "window_start": 512,
  "positions": [
    {"truth": 0.001, "frames": "position01/stream.spif"},
    {"truth": 0.0011, "frames": "position02/stream.spif"}
  ]
}
```

```powershell
python host/prepare_ab_dataset.py manifest.json --output measurement_ab.npz
```

每个位置录制时应保持W/T一致并启用S0输出；建议标定录制临时设置S0间隔为1。若间隔为100，128个参考帧需要约5.4秒（2365帧/秒时），不能按128个CCD帧的54毫秒估计。平均只降低不相关随机噪声，光源漂移和固定偏置不会按平方根衰减。暗场可留作诊断；当前FPGA没有逐像素暗场减法，不能只将S减去暗场而保持测量分子S0不变。

`host/ab_evaluate.py`在同一批原始帧上比较当前算法、线性均匀 K 重采样、自然三次样条参考，以及线性重采样后的三点功率抛物线/对数功率粗峰。输入 NPZ 包含`frames[M,N]`、`source[N]`、`k[N]`和`truth[M]`，其中N为1024或2048。每个已知位置应至少500帧，第一组位置作为唯一的加性零点校正；工具不会拟合比例掩盖系统误差。

```powershell
python host/ab_evaluate.py measurement_ab.npz --output ab_result --distance-scale 0.5 --window-start 512
```

输出`per_frame.csv`、`summary.json`和`report.md`。只有线性重采样令P95误差或最差重复性改善至少20%，才进入FPGA；线性结果距三次样条不超过5%时继续采用线性。候选RTL为预计算基址/Q0.20比例、双口BRAM相邻点读取和单乘加流水，1024点约需10.24 μs（100 MHz，不含小量流水开销），明显低于1 ms，因此设计目标仍是每秒至少1000个距离结果。当前固化FPGA尚未加入重采样。

## 启动

```powershell
python host/viewer.py
python host/viewer.py --replay build/viewer_qa/rtl_simulation.spif
```

日常使用可直接双击 `build/viewer_dist/viewer.exe`。首次在线连接选择同目录的 `CyUSB.dll`。
