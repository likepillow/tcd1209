## 文件与边界契约

容器版本为2，线上SPIF协议仍为1，不新增命令或改包长度。

每次保存独占一个新目录。目录含 `manifest.json`、`stream-00000.spif` 等分卷、`index.jsonl`、`events.jsonl`、`distance.csv`。目标卷大小1 GiB，可超过目标至后续完整包结束；USB chunk跨包时不会在chunk边缘直接切卷。校验失败、噪声和未完整尾部原样留在分卷中，不清洗。

清单只发布已flush/fsync的前缀及各卷该前缀的SHA-256。最后卷可能含不完整尾部，因此分别保存 `committed_bytes` 与 `last_complete_packet_end`。索引及事件也有提交字节上限。原子替换失败时保留上一份清单；普通回放遵守其边界。fsync不等同于对磁盘控制器/硬件断电行为的保证。

每4096包建立稀疏定位与块范围索引；ACK/配置记录另有索引。条目记录卷号、偏移、扩展帧号/时间、包类型、实际线上S/K版本。事件用 `after_packet` 定位真实确认边界；由于磁盘可能已收到后续chunk，不能把写入时的事件游标当作该包实际配置版本。局部读取扫描索引，定位所有重叠块的首末边界，仅读取这段数据；包括延迟交错的RESULT。局部校验不替代全场校验。

UTC锚点为主机接收时间，明确不是曝光时刻的同步UTC。100 MHz时基、32位frame_id、64位硬件时间单独记录；自然回绕扩展，重复/倒序显式计数。设备复位必须另开会话，旧协议无法可靠区分所有复位与回绕情形。

配置事件保存确认的完整命令payload、调用方提供的完整S/K副本和哈希。固件编号、设备唯一身份、暗场若未提供，保持未知，不能从VID/PID或旧记录推断。当前界面的历史标定仍可能只有1024/512点；D1不会伪造2048点标定。新增manifest记录本次软件源文件哈希；HDF5记录输入字节哈希及导出器代码哈希。

RAW、SPECTRUM、PHASE、RESULT分别统计完整包、前向帧、无效、未观察帧号和重复/倒序；RESULT保留设备累计丢帧/异常计数。未观察帧号可能来自主动抽帧或停止间隔，不一律解释为传输丢失。旧固件不提供权威物理启动行总数，`physical_started_lines` 和 `all_physical_lines_saved` 为null。包序号连续不能证明每一物理行都保存了RAW。

## 异常与恢复

异常关闭清单保持 `closed_cleanly=false`。恢复命令扫描实际分卷，报告已提交边界之外的字节、最后完整包、坏CRC及不确定尾部，不修改原始文件，不把找回的包标为无损实验。

写入失败后，尽力将未处理接收FIFO保存到 `uncommitted-receive.bin`，并写 `failure.json`。该诊断文件可能包含已部分写入分卷的当前chunk，**不能直接拼接回原卷**。磁盘满/不可写时连诊断文件也可能无法保存；软件无法保证保存被介质拒绝的字节。清单/失败报告会保留已接受、待写和未能接受的字节数，不能继续宣称正常记录。

90%阈值预留10%用于STOP延迟和排空。报告记录触发后的实际接收字节及按10%余量反算的最低预算；这只是本次观察下限。尤其长曝光下，STOP可能等待当前行完成，必须以最长曝光、USB缓冲和磁盘停顿实测选预算，不承诺256 MiB适用于所有情况。

## 使用命令

在 `spectral_interferometer` 目录，使用带NumPy/Tk的Python。HDF5导出另需h5py。本机测试使用Codex Python 3.12.14，h5py 3.16.0安装在 `build/d1_dependencies`，不改系统Python。

```powershell
python host/viewer.py --record-queue-mib 256 --record-volume-mib 1024
python host/viewer.py --record-metadata D:\SDPM\experiment_metadata.json
python host/viewer.py --replay D:\SDPM\run001\manifest.json
python host/session_cli.py verify D:\SDPM\run001
python host/session_cli.py summary D:\SDPM\run001
python host/session_cli.py recover D:\SDPM\run001 --report D:\SDPM\recovery001.json
python host/session_cli.py extract D:\SDPM\run001 D:\SDPM\clip001 --frame-min 1000 --frame-max 2000
python host/session_cli.py extract D:\SDPM\run001 D:\SDPM\clip002 --ticks-min 100000000 --ticks-max 200000000
python host/session_cli.py recompute D:\SDPM\run001 D:\SDPM\recomputed001 --algorithm legacy_spectral_slope_1024 --calibration D:\SDPM\calibration.npz --frame-min 1000 --frame-max 2000
python host/research_export.py D:\SDPM\run001\manifest.json D:\SDPM\hdf5_001
python scripts/check_d1.py --output build/d1_checks_new --benchmark-frames 20000
```

帧号和ticks上下界均包含端点，使用扩展整数；ticks是设备时间，不是从会话开始计的秒。所有输出目录必须尚不存在。重算使用既有 `reference.Calibration` 格式npz，由调用者明确提供与数据窗口匹配的标定；算法ID明确是既有参考，不代表D4论文方法复现或科学性能验收。

可选实验JSON整体保存并计算哈希，可填 `device_identity`、`firmware_version`、`identity_evidence`、`dark_field`（完整数值数组及像素约定）、温度和实验编号。手工填写的身份/固件应在 `identity_evidence` 说明核对来源，不表示软件进行了设备读回。S/K仍以ACK事件记录实际上传副本。
