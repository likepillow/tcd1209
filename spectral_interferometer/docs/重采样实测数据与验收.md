# 重采样实测数据与验收

本文件保留FPGA重采样升级的数据要求及实测决策。当前固化版为26100301，线性和自然三次样条重采样仅在离线软件中运行，均未通过本批收益门限。2026-10-04用户允许弃用无精度收益的粗峰功能，最终保留相位斜率主链。距离输出至少1000 Hz为要求。

## 用户采集数据

1. 固定光路、S0窗口W、曝光周期T和光源条件，提供对应1024点或2048点实测K文本；K严格单调。只有512点拟合K不足以构造1024点重采样映射。
2. 提供无干涉调制、无0/4095饱和值的光源S。推荐128帧逐像素平均，并另录暗场作诊断。当前硬件归一化尚不支持逐像素暗场减法。
3. 在覆盖实际量程的11个已知位置分别保存至少500个完整S0帧。每个位置单独记录，保存stream.spif和manifest.json；实际输出S0间隔建议设为1。间隔100时500个S0帧需要约21.1秒。记录文件中的完整帧数才是评估样本数。
4. 中间位置另采1000帧静态数据，并按位移台最小可靠步长另录一段细扫描。各位置标注已知距离、单位、可靠步长及位置不确定度。
5. 提供K单位和距离比例，例如K=2π/λ、单位rad/m、Michelson空气双程几何距离比例0.5。现有正频FFT相位约定下，降序K的距离结果为负；truth应使用相同符号，不能逐点取绝对值或改变比例来消除误差。

数据目录示例：

```text
measurement/
  source.txt
  k.txt
  input.json
  position01/stream.spif
  position01/manifest.json
  ...
  position11/stream.spif
  position11/manifest.json
```

input.json列出全部11个位置，truth填入实际已知距离；下面只展示格式，不能作为真实测量数据：

```json
{
  "source": "source.txt",
  "k": "k.txt",
  "window_start": 512,
  "period_pixels": 2114,
  "positions": [
    {"truth": 0.001, "frames": "position01/stream.spif"},
    {"truth": 0.0011, "frames": "position02/stream.spif"}
  ]
}
```

在spectral_interferometer目录中运行：

```powershell
python host/prepare_ab_dataset.py measurement/input.json --output measurement/dataset.npz
python host/ab_evaluate.py measurement/dataset.npz --output measurement/ab_report --distance-scale 0.5 --window-start 512
```

工具保持CCD无效标志、检查CRC/缺包/倒序，并拒绝记录清单中不一致的W/T。无记录清单或无W/T事件的旧数据仅保留为未确认来源，不能自动证明标定条件一致。距离只有首个参考位置允许作加性零点校正，不做全量程比例拟合。

|---|---|---|

|CCD采集和USB|同一记录256帧、2365.18帧/秒、0缺包、0 CRC错误、STOP ACK；jtag.log中USR_ACCESS=26092402|已验证；采集速率不能代替距离结果速率|
|离线算法比较|2026-10-03实测11位置，每处共同抽样1000帧，原始S/31点/101点参考平滑及当前/线性/样条比较|已完成本批评估，详见build/positions_20261003/实测评估说明.md|

|最终混合算法|离线线性重采样后三点功率峰拟合P95≈6.05 μm，对数峰拟合≈1.79 μm|不替代相位主结果；粗细差值无效率门限未标定，不直接启用|

|重采样/粗峰新链路实现签核|本批精度门限不支持部署，用户允许弃用无收益粗峰法|不实施此链路，不以当前位流冒充混合链签核；当前钳位版实现报告见ADC钳位保护验证.md|
|固化部署|钳位保护26100301已备份、写入、全片读回并Master-SPI重载；用户确认物理冷启动后，仅USB启停/S/K保持和5000结果吞吐通过|钳位保护已固化且免下载器冷启动复测通过；重采样及粗峰混合链未固化，首轮静默读驱动错误记录保留|

第一阶段依照已确认计划以真实A/B数据决定是否实施FPGA重采样。仅增加仿真数据、提高样本数量或出现软件metrics_pass，不构成真实光学门限通过。离线工具还不能自动确认静态1000帧、细扫描和测量来源；这些须结合采集记录审核。

2026-10-03用户确认测量结束后的W/T确认没有改变配置。本批静止位置比较保留带不连续标志的样本；原始标志仍保存，不等同于证明没有缺帧。当前记录没有RESULT包，离线距离来自RAW重算。参考S作31点反射边界移动平均使本批P95降至0.2083 μm；这是可撤销的本地候选，尚不能证明寄生干涉已消除，需独立复测。当前固化镜像未改变。

## 最终交付范围调整

上段“固化镜像未改变”是2026-10-03评估阶段的记录；2026-10-04已固化钳位保护，但相位解算主链不变。当前FPGA没有RESAMPLE_MAP 0x26、独立亚频点粗峰结果包或粗细差值无效判据。线性和自然三次样条重采样未过收益门限，按计划不进入FPGA；三点功率及对数峰拟合仅保留为离线研究工具。粗峰P95约6.05/1.79 μm高于当前相位法0.334 μm，用户已允许弃用无精度收益的粗峰算法，因此不实施混合链路，不将其列为待交付功能。保留当前相位主链及参考S多帧平均/可选平滑；31点参考平滑的本批P95为0.2083 μm，仍须独立光学复测。
